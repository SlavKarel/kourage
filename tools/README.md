# Публикация папки задания из VS Code

## Постоянная папка «Классные работы»

Чтобы синхронизировать локальную папку из VS Code с разделом ученика «Классные работы», выполните:

```bash
node tools/publish-classwork.mjs https://co916506.tw1.ru ЛОГИН_УЧЕНИКА ./путь-к-папке
```

Например:

```bash
node tools/publish-classwork.mjs https://co916506.tw1.ru artem ./students/Artem
```

После входа сценарий загрузит новые и изменённые файлы и уберёт из кабинета файлы, удалённые из локальной папки. Локальная папка остаётся главным источником, поэтому для обычного добавления одного файла удобнее использовать страницу «Классные работы» в браузере.

## Файлы конкретного задания

Сценарий берёт файлы из локальной папки, сохраняет структуру подпапок и публикует их в уже созданное задание Kourage. Если задание назначено группе, папка обновится у всех учеников этой группы. Повторный запуск заменит файлы с теми же путями и уберёт из задания файлы, которых больше нет в локальной папке.

Откройте терминал VS Code в корне репозитория и выполните:

```bash
node tools/publish-assignment.mjs https://co916506.tw1.ru ID_ЗАДАНИЯ ./путь-к-папке
```

Например:

```bash
node tools/publish-assignment.mjs https://co916506.tw1.ru 42 ./assignments/lesson-7
```

Номер задания виден на карточке как `Задание #42`. Сценарий попросит логин и пароль преподавателя. Пароль никуда не записывается. Нужен Node.js 20 или новее.

Поддерживаются файлы кода, TXT, Markdown, CSV, JSON, XML, YAML, SQL и Excel. Скрытые папки, `.git`, `.vscode`, `node_modules` и `__pycache__` пропускаются. Ограничения сайта: до 20 файлов и до 10 МБ на файл.
