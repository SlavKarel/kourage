# Kourage

Одностраничный кабинет преподавателя и ученика. PHP 8.1+, PDO SQLite, HTML/CSS/JavaScript. Сайт работает на Timeweb; GitHub хранит исходный код и историю изменений.

В этой версии есть ученики, групповые и индивидуальные задания, банк заданий, редактирование и переназначение выданных домашних работ, решения, проверка с баллами и комментариями, история работ, совместный Python-редактор и отдельная страница «Классные работы». У каждого ученика есть постоянная файловая папка: код и текст открываются в браузере, а её содержимое можно [синхронизировать из VS Code](tools/README.md).

Страница «Видеозвонок» создаёт персональную встречу преподавателя с выбранным учеником через бесплатный публичный сервер Jitsi Meet. Ученику не нужна ссылка: активная встреча появляется в его кабинете. Отдельный аккаунт, API-ключ и способ оплаты для звонков не требуются.

## Структура на Timeweb

```text
courage/
├── private/              # Только на хостинге, отсутствует в репозитории
│   ├── kourage.sqlite   # Ученики, пароли, задания и результаты
│   └── uploads/         # Файлы материалов и решений
└── public_html/          # Код из этого репозитория
    ├── api.php
    ├── index.html
    ├── meeting.html
    └── assets/
```

## Обновление действующего сайта

1. Сохраните свежую резервную копию сайта средствами Timeweb, включая private и текущий public_html.
2. Загрузите изменённые файлы из public_html в существующий courage/public_html. Не создавайте вложенную папку public_html/public_html и не удаляйте старую папку целиком.
3. Существующие настройки .htaccess и .user.ini сначала сравните и сохраните. В .user.ini для вложений нужны upload_max_filesize = 10M и post_max_size = 12M; если хостинг не учитывает файл, задайте их в панели PHP.
4. Папку private и базу данных не заменяйте. Таблица вложений создаётся автоматически; ученики и задания остаются в действующей базе.

Публикация файлов в GitHub сама по себе не обновляет Timeweb. Обновление запускается кнопкой Actions по инструкции в [deploy/README.md](deploy/README.md).

## Данные и резервные копии

Репозиторий не содержит базы, ключа установки, паролей реальных пользователей или загруженных материалов. Не добавляйте их даже в закрытый репозиторий. Файл .gitignore исключает их при работе через Git, но при ручной загрузке через веб-страницу GitHub проверяйте выбранные файлы самостоятельно.

GitHub сохраняет историю кода. Новые задания и ученики появляются в базе на Timeweb, поэтому резервные копии private по-прежнему нужны.

Файлы, убранные через интерфейс вложений, скрываются из задания; физические копии остаются в private/uploads. Демо открывается по адресу сайта с ?demo=1 и использует вымышленные данные.
